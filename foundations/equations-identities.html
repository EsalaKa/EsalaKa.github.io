FOUNDATIONS 03

Equations and Identities

Equations allow us to find unknown quantities from known relationships. Identities tell us that two different-looking expressions always represent the same quantity.

Why equations matter

Many practical problems give a relationship and ask for an unknown value. If a £3 starting charge plus £2 per mile gives a total cost of £13, we write

\[3+2x=13.\]

The verbal problem has become an equation that can be solved.

\[\boxed{\text{known relationship}+\text{unknown quantity}\rightarrow\text{equation}}\]

1. Equality

The symbol \(=\) means that the expressions on both sides have exactly the same value:

\[3+4=7.\]

It represents balance, not merely “the answer comes next.” Therefore \(7=3+4\) is equally valid.

2. Equations

An equation containing a variable may be true only for particular values. For example,

\[x+3=8\]

is true when \(x=5\). This value is a solution.

3. Solving while preserving balance

To solve \(2x+3=11\), subtract \(3\) from both sides and then divide both sides by \(2\):

\[2x=8,\qquad x=4.\]

We perform the same valid operation on both sides because equality must remain balanced.

4. Why the same operation works

If \(a=b\), then

\[a+c=b+c,\qquad ac=bc.\]

Division also preserves equality when the divisor is non-zero. These principles are the mathematical basis of equation rearrangement.

5. Equivalent equations

Equations such as \(x+2=6\) and \(x=4\) look different but have the same solution. Solving means replacing an equation by simpler equivalent equations until the unknown is isolated.

6. Identities

An identity is true for every allowed value:

\[2(x+3)\equiv2x+6.\]

Identities are useful because they let us replace an expression by an equivalent form that may be easier to calculate, differentiate, integrate or interpret.

7. Equation versus identity

\(x+2=5\) is true only when \(x=3\). In contrast,

\[(x+1)^2\equiv x^2+2x+1\]

is true for every real \(x\). An equation usually asks which values work?; an identity says this relationship always works.
