Rational Functions

A rational function is a quotient of two polynomial functions.

The main idea

A rational function has the form

\[ f(x)=\frac{P(x)}{Q(x)}, \]

where \(P(x)\) and \(Q(x)\) are polynomials and

\[ Q(x)\neq0. \]

The denominator cannot be zero because division by zero is undefined.

1. A simple example

Consider

\[ f(x)=\frac{1}{x}. \]

The function is defined for every real \(x\) except

\[ x=0. \]

So its domain is

\[ \mathbb R\setminus\{0\}. \]

2. Domain restrictions

For a rational function, values that make the denominator zero must be excluded.

For example,

\[ f(x)=\frac{x+1}{x-3}. \]

The denominator is zero when

\[ x=3. \]

Therefore \(x=3\) is not in the domain.

3. Vertical asymptotes

A value excluded from the domain may correspond to a vertical asymptote.

For

\[ f(x)=\frac{1}{x}, \]

the graph approaches the vertical line

\[ x=0 \]

without reaching it.

4. Horizontal behaviour

Rational functions may also approach a fixed value as \(|x|\) becomes large.

For example,

\[ f(x)=\frac{1}{x}. \]

As \(x\) becomes very large in magnitude,

\[ \frac{1}{x} \]

gets closer to \(0\).

So the graph approaches the horizontal line

\[ y=0. \]

5. Simplifying rational expressions

A rational expression can sometimes be simplified by cancelling common factors.

For example,

\[ \frac{x^2-1}{x-1} \]

factorises as

\[ \frac{(x-1)(x+1)}{x-1}. \]

For \(x\neq1\),

\[ \frac{x^2-1}{x-1}=x+1. \]

But \(x=1\) is still excluded from the original function.

6. A removable discontinuity

The previous example behaves like

\[ y=x+1 \]

for every allowed value of \(x\), but the point corresponding to \(x=1\) is missing.

This missing point is called a removable discontinuity.

7. Rational functions and limits

Rational functions are useful for introducing limits because the graph may approach values that are not actually reached.

For example,

\[ \frac{x^2-1}{x-1} \]

is undefined at \(x=1\), but for nearby values it behaves like

\[ x+1. \]

So the function approaches

\[ 2 \]

as \(x\) approaches \(1\).

8. Why rational functions matter for calculus

Rational functions naturally introduce several important calculus ideas: domain restrictions, asymptotes, continuity and limits.

\[ \text{rational functions} \longrightarrow \text{limits} \longrightarrow \text{continuity} \longrightarrow \text{derivatives} \]
