Algebraic Expressions

Algebra uses symbols to represent numbers and relationships between quantities.

The main idea

An algebraic expression is a mathematical combination of numbers, variables and operations.

\[ 3x^2-5x+7 \]

This expression contains three terms and describes a value that depends on \(x\).

1. Variables

A variable is a symbol that represents a number whose value may change or may not yet be known.

\[ x,\qquad y,\qquad t \]

For example, in

\[ x+4, \]

the value of the expression depends on the value of \(x\).

2. Constants

A constant is a fixed value.

In

\[ 3x+5, \]

the number \(5\) is a constant.

3. Coefficients

A coefficient is a number multiplying a variable.

In

\[ 7x, \]

the coefficient of \(x\) is \(7\).

If no number is written, the coefficient is \(1\):

\[ x=1x. \]

4. Terms

Terms are the parts of an expression separated by \(+\) or \(-\).

For example,

\[ 4x^2-3x+6 \]

has three terms:

\[ 4x^2,\qquad -3x,\qquad 6. \]

5. What an expression represents

An expression does not make a statement that is true or false. It represents a mathematical value.

For example,

\[ 2x+1 \]

is an expression.

If \(x=3\), then

\[ 2x+1=2(3)+1=7. \]

6. Expression versus equation

An expression has no equality sign:

\[ 3x+2. \]

An equation states that two expressions are equal:

\[ 3x+2=11. \]

This distinction becomes important when solving equations and later when working with functions.
