FUNCTIONS 05

Quadratic Functions

A quadratic function contains a squared variable and has a curved graph called a parabola.

The main idea

A quadratic function has the form

\[ f(x)=ax^2+bx+c, \qquad a\neq0. \]

The highest power of \(x\) is \(2\), which is what makes the function quadratic.

1. The shape of the graph

The graph of a quadratic function is a parabola.

If

\[ a>0, \]

the parabola opens upward.

If

\[ a<0, \]

the parabola opens downward.

2. A simple example

Consider

\[ f(x)=x^2. \]

Then

\[ f(-2)=4, \qquad f(-1)=1, \qquad f(0)=0, \qquad f(1)=1, \qquad f(2)=4. \]

The graph is symmetric about the \(y\)-axis.

3. Roots

A root is an input where the function has value zero.

So roots satisfy

\[ f(x)=0. \]

For example,

\[ f(x)=x^2-5x+6. \]

Factorising gives

\[ f(x)=(x-2)(x-3). \]

Therefore the roots are

\[ x=2 \qquad\text{and}\qquad x=3. \]

On the graph, these are the points where the curve crosses the \(x\)-axis.

4. The turning point

A parabola has one turning point.

For

\[ f(x)=x^2, \]

the turning point is

\[ (0,0). \]

If the parabola opens upward, the turning point is a minimum. If it opens downward, it is a maximum.

5. Completing the square

A quadratic can often be rewritten in the form

\[ f(x)=a(x-h)^2+k. \]

This form makes the turning point easy to identify:

\[ (h,k). \]

For example,

\[ x^2-4x+7 \]

can be written as

\[ (x-2)^2+3. \]

So the turning point is

\[ (2,3). \]

6. The axis of symmetry

The parabola is symmetric about the vertical line through its turning point.

For

\[ f(x)=a(x-h)^2+k, \]

the axis of symmetry is

\[ x=h. \]

7. The quadratic formula

For

\[ ax^2+bx+c=0, \]

the solutions are

\[ x= \frac{-b\pm\sqrt{b^2-4ac}}{2a}. \]

This formula finds the roots even when factorisation is not simple.

8. The discriminant

The expression

\[ b^2-4ac \]

is called the discriminant.

It tells us how many real roots the quadratic has.

\[ b^2-4ac>0 \]

gives two distinct real roots,

\[ b^2-4ac=0 \]

gives one repeated real root, and

\[ b^2-4ac<0 \]

gives no real roots.

9. Why quadratic functions matter for calculus

Unlike a straight line, a quadratic curve does not have a constant slope.

For example, for

\[ f(x)=x^2, \]

the curve becomes steeper as \(|x|\) increases.

Calculus allows us to measure the slope at each point.

\[ f(x)=x^2 \quad\longrightarrow\quad f'(x)=2x. \]
