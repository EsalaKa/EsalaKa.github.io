FUNCTIONS 03

Domain and Range

The domain describes the allowed inputs of a function. The range describes the outputs the function can produce.

The main idea

A function does not necessarily accept every possible number as an input, and it does not necessarily produce every possible number as an output.

\[ \boxed{\text{Domain}} \quad \xrightarrow{\quad f\quad} \quad \boxed{\text{Range}} \]

The domain concerns inputs. The range concerns actual outputs.

1. Domain

The domain of a function is the set of values that are allowed as inputs.

For example,

\[ f(x)=x^2 \]

is defined for every real number \(x\).

Therefore its domain is

\[ \mathbb R. \]

2. Range

The range is the set of values that the function actually produces.

For

\[ f(x)=x^2, \]

the output cannot be negative when \(x\) is real.

Therefore,

\[ f(x)\geq0. \]

Its range is

\[ [0,\infty). \]

3. Domain and range are different ideas

For

\[ f(x)=x^2, \]

the domain is

\[ (-\infty,\infty), \]

while the range is

\[ [0,\infty). \]

So the possible inputs and possible outputs need not be the same set.

4. Division can restrict the domain

Consider

\[ f(x)=\frac{1}{x}. \]

Division by zero is undefined, so \(x=0\) cannot be an input.

Therefore the domain is

\[ \mathbb R\setminus\{0\}. \]

This means all real numbers except \(0\).

5. Square roots can restrict the domain

Consider the real-valued function

\[ f(x)=\sqrt{x}. \]

A negative real number does not have a real square root. Therefore,

\[ x\geq0. \]

The domain is

\[ [0,\infty). \]

The outputs are also non-negative, so the range is

\[ [0,\infty). \]

6. The domain may be chosen

Sometimes a formula is mathematically defined for many values, but the problem restricts which inputs are relevant.

For example, suppose

\[ P(t)=100e^{0.2t} \]

represents a population after time \(t\).

The formula itself can be evaluated for negative \(t\), but if \(t=0\) represents the beginning of the observation period, the model may use

\[ t\geq0. \]

The context therefore helps determine the appropriate domain.

7. Domain restrictions from several conditions

Consider

\[ f(x)=\frac{\sqrt{x-2}}{x-5}. \]

The square root requires

\[ x-2\geq0, \]

so

\[ x\geq2. \]

The denominator also requires

\[ x\neq5. \]

Both conditions must hold. Therefore the domain is

\[ [2,5)\cup(5,\infty). \]

8. Reading domain and range from a graph

The domain can be understood as the set of \(x\)-values covered by a graph.

The range can be understood as the set of \(y\)-values reached by the graph.

So, geometrically:

\[ \text{domain} \longleftrightarrow \text{horizontal extent}, \] \[ \text{range} \longleftrightarrow \text{vertical extent}. \]

9. Codomain and range

The codomain is the set in which the outputs are declared to lie. The range contains the outputs that are actually produced.

For example, suppose

\[ f:\mathbb R\to\mathbb R, \qquad f(x)=x^2. \]

The codomain is \(\mathbb R\), but the range is only

\[ [0,\infty). \]

So the range is contained within the codomain, but they need not be equal.

10. Function notation with domain and codomain

A function may be written formally as

\[ f:A\to B. \]

This is read as “\(f\) maps \(A\) to \(B\)”.

Here \(A\) is the domain and \(B\) is the codomain. For each allowed input \(x\in A\), the function assigns one output \(f(x)\in B\).
