Powers and Roots

Powers describe repeated multiplication. Roots reverse the operation of raising to a power.

The main idea

In

\[ a^n \]

\(a\) is the base and \(n\) is the exponent or index.

For a positive integer \(n\),

\[ a^n = \underbrace{a\times a\times\cdots\times a}_{n\text{ factors}}. \]

1. Multiplying powers with the same base

When powers with the same base are multiplied, their exponents add:

\[ a^m a^n=a^{m+n}. \]

For example,

\[ x^2x^3 = (x x)(x x x) = x^5. \]

So the index law follows directly from counting the total number of factors.

2. Dividing powers with the same base

When powers with the same non-zero base are divided, their exponents subtract:

\[ \frac{a^m}{a^n}=a^{m-n}, \qquad a\neq0. \]

For example,

\[ \frac{x^5}{x^2} = \frac{x x x x x}{x x} = x^3. \]

3. A power raised to another power

When a power is raised to another power, the exponents multiply:

\[ (a^m)^n=a^{mn}. \]

For example,

\[ (x^2)^3 = x^2x^2x^2 = x^6. \]

4. The zero exponent

For any non-zero \(a\),

\[ a^0=1. \]

This follows from the division law:

\[ \frac{a^m}{a^m} = a^{m-m} = a^0. \]

But

\[ \frac{a^m}{a^m}=1, \]

so \(a^0=1\).

5. Negative exponents

A negative exponent represents a reciprocal:

\[ a^{-n}=\frac{1}{a^n}, \qquad a\neq0. \]

For example,

\[ x^{-2}=\frac{1}{x^2}. \]

The negative sign in the exponent does not make the number itself negative.

6. Roots

A root reverses a power.

For example,

\[ 3^2=9 \]

so

\[ \sqrt{9}=3. \]

More generally,

\[ \sqrt[n]{a}=b \]

means

\[ b^n=a. \]

7. Fractional exponents

Roots can be written using fractional exponents:

\[ a^{1/n}=\sqrt[n]{a}. \]

Therefore,

\[ a^{m/n} = \left(\sqrt[n]{a}\right)^m = \sqrt[n]{a^m}, \]

whenever these expressions are defined in the real numbers.

For example,

\[ 8^{1/3}=\sqrt[3]{8}=2. \]

8. A useful distinction

The symbol

\[ \sqrt{9} \]

means the principal, non-negative square root, so

\[ \sqrt{9}=3. \]

But the equation

\[ x^2=9 \]

has two real solutions:

\[ x=3 \qquad\text{or}\qquad x=-3. \]

The square-root symbol and the solutions of a squared equation are therefore not the same idea.
