FUNCTIONS 04

Linear Functions

A linear function changes at a constant rate and has a straight-line graph.

The main idea

A linear function has the form

\[ f(x)=mx+c. \]

The constant \(m\) gives the rate of change, and \(c\) gives the output when \(x=0\).

1. The gradient

The number \(m\) is the gradient of the line.

It tells us how much the output changes when the input increases by one unit.

For example, in

\[ f(x)=3x+2, \]

the gradient is \(3\).

So if \(x\) increases by \(1\), \(f(x)\) increases by \(3\).

2. The intercept

The number \(c\) is the vertical intercept.

It is the value of the function when \(x=0\).

For

\[ f(x)=3x+2, \]

we have

\[ f(0)=2. \]

So the graph crosses the \(y\)-axis at

\[ (0,2). \]

3. Constant rate of change

For any two points on a straight line,

\[ (x_1,y_1) \qquad\text{and}\qquad (x_2,y_2), \]

the gradient is

\[ m= \frac{y_2-y_1}{x_2-x_1}. \]

For a linear function, this value is the same no matter which two points are chosen.

4. Example

Suppose

\[ f(x)=2x+1. \]

Then

\[ f(1)=3, \]

and

\[ f(4)=9. \]

So

\[ \Delta x=4-1=3 \]

and

\[ \Delta y=9-3=6. \]

Therefore,

\[ \frac{\Delta y}{\Delta x} = \frac63 = 2. \]

This agrees with the coefficient of \(x\).

5. Positive and negative gradient

If

\[ m>0, \]

the function increases as \(x\) increases.

If

\[ m<0, \]

the function decreases as \(x\) increases.

If

\[ m=0, \]

then

\[ f(x)=c, \]

so the graph is horizontal.

6. Finding a linear function from two points

Suppose a line passes through

\[ (1,3) \qquad\text{and}\qquad (4,9). \]

First find the gradient:

\[ m= \frac{9-3}{4-1} = 2. \]

So the function has the form

\[ f(x)=2x+c. \]

Using the point \((1,3)\),

\[ 3=2(1)+c, \]

so

\[ c=1. \]

Therefore,

\[ f(x)=2x+1. \]

7. Linear models

Linear functions are useful when a quantity changes by the same amount per unit change in another quantity.

For example,

\[ C(n)=5n+20 \]

could represent a cost consisting of a fixed charge of \(20\) plus \(5\) for each unit \(n\).

The gradient \(5\) is the cost per additional unit.

8. Why linear functions matter for calculus

A straight line has a constant slope.

A curve usually does not.

Calculus develops a way to measure the slope of a curve at a single point by comparing it locally with a straight line.

\[ \text{straight-line slope} \quad\longrightarrow\quad \text{tangent slope} \quad\longrightarrow\quad \frac{dy}{dx}. \]
