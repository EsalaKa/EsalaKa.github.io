FUNCTIONS 02

Function Notation

Function notation identifies a function, its input and the corresponding output.

The main idea

If a function is called \(f\) and its input is \(x\), its output is written

\[ f(x). \]

This is read as “\(f\) of \(x\)”. It does not mean \(f\) multiplied by \(x\).

1. Defining a function

Consider

\[ f(x)=2x+3. \]

Here \(f\) is the name of the function, \(x\) is the input, and \(2x+3\) tells us how the output is calculated.

So

\[ x \longmapsto 2x+3. \]

2. Evaluating a function

To find \(f(4)\), replace \(x\) by \(4\):

\[ f(4)=2(4)+3=11. \]

Thus \(f(4)\) means the output of \(f\) when the input is \(4\).

3. The input can be any allowed expression

The input does not have to be a single number.

If

\[ f(x)=x^2+1, \]

then

\[ f(a)=a^2+1. \]

Similarly,

\[ f(x+h)=(x+h)^2+1. \]

The entire expression \(x+h\) replaces \(x\).

4. Function names

The letter \(f\) is only a name. Other letters may be used.

\[ g(x)=x^2, \qquad h(x)=3x-1. \]

For example,

\[ g(2)=4, \qquad h(2)=5. \]

Different function names allow us to distinguish different relationships.

5. \(y\) and \(f(x)\)

The expressions

\[ y=2x+1 \]

and

\[ f(x)=2x+1 \]

can describe the same relationship.

Writing \(f(x)\) makes the dependence of the output on the input explicit:

\[ y=f(x). \]

6. Function notation does not mean multiplication

Ordinary multiplication may be written

\[ f x. \]

But

\[ f(x) \]

has a different meaning: it denotes the value of the function \(f\) at the input \(x\).

The brackets specify the input to the function.

7. Comparing two function values

Suppose

\[ f(x)=x^2. \]

Then

\[ f(2)=4 \]

and

\[ f(5)=25. \]

The difference in the outputs is

\[ f(5)-f(2)=21. \]

Function notation therefore lets us describe changes in output precisely.

8. A notation that leads to calculus

Suppose the input changes from \(x\) to

\[ x+\Delta x. \]

The output changes from

\[ f(x) \]

to

\[ f(x+\Delta x). \]

Therefore the change in the output is

\[ \Delta y = f(x+\Delta x)-f(x). \]

The corresponding average rate of change is

\[ \frac{\Delta y}{\Delta x} = \frac{f(x+\Delta x)-f(x)}{\Delta x}. \]

This expression will later lead directly to the definition of the derivative.
