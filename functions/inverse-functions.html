Inverse Functions

An inverse function reverses the action of the original function, exchanging inputs and outputs.

The main idea

If

\[f(a)=b,\]

then the inverse function satisfies

\[\boxed{f^{-1}(b)=a}.\]

The original function and its inverse describe the same relationship in opposite directions.

1. A simple inverse

If

\[f(x)=x+3,\]

then the inverse must undo the addition:

\[\boxed{f^{-1}(x)=x-3}.\]
\(x\)
↓ add 3
\(x+3\)
↓ subtract 3
\(x\)

2. Inverse notation

The notation \(f^{-1}(x)\) means the inverse function.

It does not mean

\[\frac1{f(x)}.\]
\(f^{-1}\) = reverse function

\(1/f\) = reciprocal

these are different ideas

3. How to find an inverse

For

\[f(x)=2x+5,\]

write \(y=2x+5\), solve for \(x\), then rename the variables:

\[x=\frac{y-5}{2}.\]

Hence

\[\boxed{f^{-1}(x)=\frac{x-5}{2}}.\]
\(y=2x+5\)
↓ solve for \(x\)
\(x=(y-5)/2\)
↓ swap names
\(f^{-1}(x)=(x-5)/2\)

4. Checking an inverse

A correct inverse returns the original input:

\[f^{-1}(f(x))=x.\]

For the example above,

\[f^{-1}(2x+5)=\frac{(2x+5)-5}{2}=x.\]
apply \(f\)
then apply \(f^{-1}\)
↓
return to the starting value

5. Graphs of inverse functions

If \((a,b)\) lies on \(y=f(x)\), then \((b,a)\) lies on \(y=f^{-1}(x)\).

Therefore the two graphs are reflections in the line

\[\boxed{y=x}.\]

The graph compares \(y=2x+1\) with its inverse \(y=(x-1)/2\).

6. Not every function has an inverse

For

\[f(x)=x^2,\]

both \(2\) and \(-2\) give the same output:

\[f(2)=f(-2)=4.\]

So \(x^2\) is not one-to-one on all real numbers.

\(-2\to4\)
\(2\to4\)

two inputs, one output
↓
inverse would be ambiguous

7. The horizontal line test

A function has an inverse on its domain only if every horizontal line meets its graph at most once.

The line \(y=4\) meets \(y=x^2\) at both \((-2,4)\) and \((2,4)\), so the test fails.

8. Restricting the domain

If we restrict

\[f(x)=x^2\]

to \(x\ge0\), each output has only one allowed input. Then

\[\boxed{f^{-1}(x)=\sqrt{x}}.\]

The two graphs are reflections in \(y=x\).

9. Domain and range swap

When \(f\) has an inverse,

\[\boxed{\operatorname{Dom}(f)=\operatorname{Ran}(f^{-1})},\]\[\boxed{\operatorname{Ran}(f)=\operatorname{Dom}(f^{-1})}.\]
domain of \(f\)
↔
range of \(f^{-1}\)

range of \(f\)
↔
domain of \(f^{-1}\)

10. Exponential and logarithmic inverses

The functions

\[y=e^x\quad\text{and}\quad y=\ln x\]

are inverses because

\[\ln(e^x)=x,\qquad e^{\ln x}=x\quad(x>0).\]

11. Why inverse functions matter for calculus

Inverse functions are essential for logarithms, inverse trigonometric functions and solving equations.

The derivative of an inverse also satisfies

\[\boxed{(f^{-1})'(x)=\frac{1}{f'(f^{-1}(x))}},\]

where the denominator is non-zero.

function
↔ inverse function
↔ reciprocal slope relationship
Key takeaways

An inverse reverses a function. Its graph is reflected in \(y=x\), domain and range exchange roles, and a function must be one-to-one on its chosen domain before an inverse function can exist.
