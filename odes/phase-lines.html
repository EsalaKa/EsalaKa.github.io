DIFFERENTIAL EQUATIONS 06

Phase Lines and Stability

A phase line shows how solutions of an autonomous differential equation move between equilibrium states.

The main idea

For an autonomous equation

\[ \frac{dy}{dt}=f(y), \]

the sign of \(f(y)\) determines whether \(y\) increases or decreases.

\[ \boxed{ f(y)>0 \Rightarrow y\text{ increases} } \] \[ \boxed{ f(y)<0 \Rightarrow y\text{ decreases} } \]

A phase line records these directions along the \(y\)-axis.

1. Equilibrium points

Equilibria occur where

\[ f(y)=0. \]

At such values,

\[ \frac{dy}{dt}=0, \]

so a solution that starts there stays there.

2. Example

Consider

\[ \frac{dy}{dt}=y(2-y). \]

Equilibria satisfy

\[ y(2-y)=0. \]

Therefore,

\[ y=0 \]

and

\[ y=2. \]

3. Examine the sign between equilibria

The equilibrium values divide the phase line into three regions:

\[ y<0, \qquad 02. \]

Choose one test value in each region.

If \(y=-1\),

\[ y(2-y)=(-1)(3)<0. \]

So solutions move downward.

If \(y=1\),

\[ y(2-y)=1>0. \]

So solutions move upward.

If \(y=3\),

\[ y(2-y)=3(-1)<0. \]

So solutions move downward.

4. The phase line

5. Stable equilibrium

Look at the arrows near

\[ y=2. \]

Below \(2\), solutions move upward. Above \(2\), solutions move downward.

So nearby solutions move toward \(y=2\).

\[ \boxed{ y=2 \text{ is stable} } \]

6. Unstable equilibrium

Near

\[ y=0, \]

solutions move away from the equilibrium on both sides.

Therefore,

\[ \boxed{ y=0 \text{ is unstable} } \]

7. Stable versus unstable

A stable equilibrium has arrows pointing toward it:

\[ \boxed{ \rightarrow\; y^*\; \leftarrow } \]

An unstable equilibrium has arrows pointing away:

\[ \boxed{ \leftarrow\; y^*\; \rightarrow } \]

8. Semi-stable equilibria

Sometimes solutions move toward an equilibrium from one side but away from it on the other.

For example, consider

\[ \frac{dy}{dt}=y^2. \]

The only equilibrium is

\[ y=0. \]

For \(y<0\),

\[ y^2>0, \]

so solutions increase toward \(0\).

For \(y>0\),

\[ y^2>0, \]

so solutions move upward away from \(0\).

This is called a semi-stable equilibrium.

9. Stability using the derivative of \(f\)

Suppose \(y^*\) is an equilibrium:

\[ f(y^*)=0. \]

A useful local test is

\[ \boxed{ f'(y^*)<0 \Rightarrow \text{locally asymptotically stable} } \] \[ \boxed{ f'(y^*)>0 \Rightarrow \text{unstable} } \]

If

\[ f'(y^*)=0, \]

the test is inconclusive and we inspect the signs directly.

10. Why does \(f'(y^*)<0\) imply stability?

Near the equilibrium, the function can be approximated by

\[ f(y) \approx f'(y^*)(y-y^*). \]

Since

\[ f(y^*)=0, \]

the dynamics become approximately

\[ \frac{dy}{dt} \approx f'(y^*)(y-y^*). \]

If \(f'(y^*)<0\), deviations from the equilibrium tend to shrink.

11. Apply the derivative test

For

\[ f(y)=y(2-y)=2y-y^2, \]

we have

\[ f'(y)=2-2y. \]

At \(y=0\),

\[ f'(0)=2>0. \]

So \(y=0\) is unstable.

At \(y=2\),

\[ f'(2)=-2<0. \]

So \(y=2\) is stable.

12. Long-term behaviour

The phase line lets us predict what happens as

\[ t\to\infty. \]

For the equation

\[ y'=y(2-y), \]

if

\[ 0 then the solution increases toward

\[ 2. \]

If

\[ y(0)>2, \]

the solution decreases toward

\[ 2. \]

So in both cases,

\[ y(t)\to2. \]

13. Basin of attraction

The set of initial values whose solutions move toward a stable equilibrium is called its basin of attraction.

In a one-dimensional system, the phase line often makes this region easy to identify.

14. Phase line versus solution graph

A phase line does not plot \(y\) against time.

Instead, it shows possible values of \(y\) and the direction in which the state moves.

\[ \boxed{ \text{phase line} = \text{state direction} } \] \[ \boxed{ \text{solution graph} = y(t)\text{ through time} } \]

15. Why phase lines are useful

An explicit formula for the solution may be difficult or unnecessary.

A phase line can still reveal:

\[ \text{equilibria}, \] \[ \text{stability}, \] \[ \text{direction of movement}, \]

and

\[ \text{long-term behaviour}. \]

16. Practical method

\[ \boxed{ 1.\; \text{Write }y'=f(y) } \] \[ \boxed{ 2.\; \text{Solve }f(y)=0 } \] \[ \boxed{ 3.\; \text{Divide the line into intervals} } \] \[ \boxed{ 4.\; \text{Determine the sign of }f(y) } \] \[ \boxed{ 5.\; \text{Draw arrows} } \] \[ \boxed{ 6.\; \text{Classify each equilibrium} } \] \[ \boxed{ 7.\; \text{Describe long-term behaviour} } \]

17. The central idea

\[ \boxed{ y'=f(y) } \] \[ \downarrow \] \[ \boxed{ f(y)=0 \Rightarrow \text{equilibria} } \] \[ \downarrow \] \[ \boxed{ \text{sign of }f(y) \Rightarrow \text{movement} } \] \[ \downarrow \] \[ \boxed{ \text{movement near equilibria} \Rightarrow \text{stability} } \]

Phase-line analysis lets us understand the behaviour of a differential equation before solving it explicitly.
