DIFFERENTIAL EQUATIONS 05

Autonomous Differential Equations

An autonomous differential equation gives the rate of change as a function of the current state, without explicit dependence on time.

The main idea

An autonomous first-order differential equation has the form

\[ \boxed{ \frac{dy}{dt}=f(y) } \]

The rate of change depends on the current value of \(y\), but time \(t\) does not appear explicitly on the right-hand side.

1. Why it is called autonomous

Consider

\[ \frac{dy}{dt}=y(1-y). \]

To determine the rate of change, we only need to know the current value of \(y\).

We do not need to know the current time.

For example, whenever

\[ y=\frac12, \]

the rate is

\[ \frac{dy}{dt} = \frac12\left(1-\frac12\right) = \frac14. \]

This is true regardless of when the state \(y=1/2\) occurs.

2. Compare with a non-autonomous equation

The equation

\[ \frac{dy}{dt}=ty \]

is not autonomous because the rate depends explicitly on time \(t\).

By contrast,

\[ \frac{dy}{dt}=y^2-1 \]

is autonomous.

3. Equilibrium solutions

An equilibrium occurs where the rate of change is zero.

For

\[ \frac{dy}{dt}=f(y), \]

equilibria satisfy

\[ \boxed{ f(y)=0 } \]

At such a state,

\[ \frac{dy}{dt}=0, \]

so the solution remains constant.

4. Example

Consider

\[ \frac{dy}{dt}=y(1-y). \]

Equilibria occur when

\[ y(1-y)=0. \]

Therefore,

\[ y=0 \]

or

\[ y=1. \]

So the constant functions

\[ \boxed{ y(t)=0 } \]

and

\[ \boxed{ y(t)=1 } \]

are equilibrium solutions.

5. The sign of the derivative

The sign of

\[ f(y) \]

tells us the direction in which the solution moves.

If

\[ f(y)>0, \]

then

\[ \frac{dy}{dt}>0, \]

so \(y\) increases.

If

\[ f(y)<0, \]

then \(y\) decreases.

6. Sign analysis for the logistic example

For

\[ \frac{dy}{dt}=y(1-y), \]

consider three regions.

If

\[ y<0, \]

then

\[ y(1-y)<0, \]

so \(y\) decreases.

If

\[ 0 then

\[ y(1-y)>0, \]

so \(y\) increases.

If

\[ y>1, \]

then

\[ y(1-y)<0, \]

so \(y\) decreases.

7. Phase line

This information can be represented on a phase line.

The arrows show whether solutions move toward larger or smaller values of \(y\).

8. Stable equilibrium

An equilibrium is stable if nearby solutions move toward it.

For the equation

\[ \frac{dy}{dt}=y(1-y), \]

solutions below \(1\) but above \(0\) increase toward \(1\), while solutions above \(1\) decrease toward \(1\).

Therefore,

\[ \boxed{ y=1 \text{ is a stable equilibrium} } \]

9. Unstable equilibrium

Near \(y=0\), solutions move away from the equilibrium.

Values slightly above \(0\) increase, while values slightly below \(0\) decrease.

Therefore,

\[ \boxed{ y=0 \text{ is an unstable equilibrium} } \]

10. Stability from signs

Suppose \(y^*\) is an equilibrium.

If arrows on both sides point toward \(y^*\), it is stable.

\[ \rightarrow\; y^*\; \leftarrow \]

means stable.

If arrows point away,

\[ \leftarrow\; y^*\; \rightarrow \]

the equilibrium is unstable.

11. Stability using \(f'(y^*)\)

For a one-dimensional autonomous equation

\[ y'=f(y), \]

a useful local test is based on

\[ f'(y^*). \]

If

\[ f'(y^*)<0, \]

the equilibrium is typically locally asymptotically stable.

If

\[ f'(y^*)>0, \]

it is unstable.

12. Apply the derivative test

For

\[ f(y)=y(1-y)=y-y^2, \]

we have

\[ f'(y)=1-2y. \]

At \(y=0\),

\[ f'(0)=1>0, \]

so \(y=0\) is unstable.

At \(y=1\),

\[ f'(1)=-1<0, \]

so \(y=1\) is stable.

13. Equilibrium analysis without solving the ODE

One important advantage of autonomous equations is that we can often understand long-term behaviour without finding an explicit formula for \(y(t)\).

By finding equilibria and examining the sign of \(f(y)\), we can determine where solutions move.

\[ \boxed{ \text{equilibria} + \text{sign of }f(y) \longrightarrow \text{qualitative behaviour} } \]

14. Logistic population model

A common autonomous model is

\[ \frac{dP}{dt} = rP\left(1-\frac{P}{K}\right), \]

where

\[ r>0 \]

is a growth parameter and \(K>0\) is the carrying capacity.

The equilibria are

\[ P=0 \]

and

\[ P=K. \]

15. Meaning of the carrying capacity

If

\[ 0 then

\[ \frac{dP}{dt}>0, \]

so the population increases.

If

\[ P>K, \]

then

\[ \frac{dP}{dt}<0, \]

so the population decreases.

Thus solutions tend toward

\[ P=K. \]

The carrying capacity is therefore a stable equilibrium.

16. Direction field idea

For an autonomous equation,

\[ \frac{dy}{dt}=f(y), \]

all points with the same \(y\)-coordinate have the same slope.

This means a direction field has horizontal bands of equal slope.

Autonomous structure therefore makes the geometry of the differential equation especially clear.

17. Equilibrium solutions must be checked before separation

Suppose

\[ \frac{dy}{dt}=f(y). \]

To separate variables, we may write

\[ \frac{1}{f(y)}\,dy=dt. \]

But this division requires

\[ f(y)\neq0. \]

Values satisfying

\[ f(y)=0 \]

are precisely the equilibrium solutions.

So they must be identified separately before dividing.

18. The practical method

\[ \boxed{ 1.\; \text{Write the equation as }y'=f(y) } \] \[ \boxed{ 2.\; \text{Find equilibria from }f(y)=0 } \] \[ \boxed{ 3.\; \text{Determine the sign of }f(y)\text{ between equilibria} } \] \[ \boxed{ 4.\; \text{Draw the phase line} } \] \[ \boxed{ 5.\; \text{Classify stable and unstable equilibria} } \] \[ \boxed{ 6.\; \text{Infer the long-term behaviour} } \]

19. The central idea

\[ \boxed{ \frac{dy}{dt}=f(y) } \] \[ \downarrow \] \[ \boxed{ f(y)=0 \Rightarrow \text{equilibria} } \] \[ \downarrow \] \[ \boxed{ \text{sign of }f(y) \Rightarrow \text{direction and stability} } \]

Autonomous equations show that differential equations can often be understood qualitatively even before they are solved explicitly.
