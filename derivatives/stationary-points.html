DIFFERENTIATION 13

Stationary Points and Turning Points

Stationary points occur where the derivative is zero. They often identify maxima, minima or other important features of a graph.

The main idea

At a stationary point,

\[ \boxed{ \frac{dy}{dx}=0 } \]

So the tangent to the graph is horizontal.

1. Why the derivative is zero

The derivative gives the gradient of the tangent.

A horizontal tangent has gradient

\[ 0. \]

Therefore stationary points are found by solving

\[ f'(x)=0. \]

2. A simple example

Consider

\[ f(x)=x^2. \]

Then

\[ f'(x)=2x. \]

Set the derivative equal to zero:

\[ 2x=0. \]

Therefore,

\[ x=0. \]

The corresponding function value is

\[ f(0)=0. \]

So the stationary point is

\[ (0,0). \]

3. Minimum point

For

\[ f(x)=x^2, \]

the graph decreases before \(x=0\) and increases after \(x=0\).

So the stationary point is a minimum.

4. Maximum point

Consider

\[ f(x)=-x^2+4. \]

Then

\[ f'(x)=-2x. \]

So the stationary point occurs at

\[ x=0. \]

Since

\[ f(0)=4, \]

the stationary point is

\[ (0,4). \]

The graph increases before this point and decreases after it, so it is a maximum.

5. Using the sign of the first derivative

The sign of \(f'(x)\) tells us whether the function is increasing or decreasing.

If

\[ f'(x)>0, \]

the function is increasing.

If

\[ f'(x)<0, \]

the function is decreasing.

So:

\[ +\rightarrow- \quad\Rightarrow\quad \text{local maximum} \] \[ -\rightarrow+ \quad\Rightarrow\quad \text{local minimum} \]

6. Second derivative test

At a stationary point \(x=a\), the second derivative can often classify the point.

If

\[ f''(a)>0, \]

the graph is concave upward, so the point is a local minimum.

If

\[ f''(a)<0, \]

the graph is concave downward, so the point is a local maximum.

\[ \boxed{ f'(a)=0,\quad f''(a)>0 \Rightarrow \text{minimum} } \] \[ \boxed{ f'(a)=0,\quad f''(a)<0 \Rightarrow \text{maximum} } \]

7. Example with the second derivative test

Let

\[ f(x)=x^2-4x+7. \]

Then

\[ f'(x)=2x-4. \]

Set

\[ 2x-4=0, \]

giving

\[ x=2. \]

Now

\[ f''(x)=2. \]

Since

\[ f''(2)=2>0, \]

the stationary point is a minimum.

Its \(y\)-coordinate is

\[ f(2)=3. \]

So the minimum point is

\[ (2,3). \]

8. Not every stationary point is a turning point

Consider

\[ f(x)=x^3. \]

Then

\[ f'(x)=3x^2. \]

So

\[ f'(0)=0. \]

Thus \(x=0\) is stationary.

But the function is increasing on both sides of \(0\), so the graph does not turn there.

This is a stationary point of inflection.

9. The second derivative can be inconclusive

For

\[ f(x)=x^4, \]

we have

\[ f'(x)=4x^3 \]

and

\[ f''(x)=12x^2. \]

At \(x=0\),

\[ f''(0)=0. \]

So the second derivative test does not decide the type of stationary point.

We then examine the behaviour of \(f'(x)\) on either side.

10. Why stationary points matter

Stationary points identify locations where a function may change from increasing to decreasing or vice versa.

They are therefore central to optimisation.

\[ \boxed{ f'(x)=0 \quad\longrightarrow\quad \text{candidate for maximum, minimum or stationary inflection} } \]

12. The practical method

\[ \boxed{ 1.\; \text{Find }f'(x) } \] \[ \boxed{ 2.\; \text{Solve }f'(x)=0 } \] \[ \boxed{ 3.\; \text{Find the corresponding }y\text{-values} } \] \[ \boxed{ 4.\; \text{Classify each point} } \]

Classification can be done using the sign of \(f'(x)\), the second derivative, or both.
