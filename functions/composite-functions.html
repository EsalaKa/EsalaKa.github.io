FUNCTIONS 11

Composite Functions

A composite function uses the output of one function as the input of another.

The main idea

\[(f\circ g)(x)=f(g(x)).\]

The inside function acts first.

1. A simple example

If \(g(x)=x+2\) and \(f(x)=x^2\), then \(f(g(x))=(x+2)^2\).

2. The order matters

In general, \(f(g(x))\neq g(f(x))\). For these functions, the two resulting parabolas are visibly different.

3. Think of functions as stages

\[x\longrightarrow g(x)\longrightarrow f(g(x)).\]

4. Evaluating a composite function

If \(g(x)=2x+1\), \(f(x)=x^2\), then \((f\circ g)(3)=49\).

5. Reading nested functions

Read nested functions from the inside outward.

6. Domain of a composite function

For \(f(g(x))=\sqrt{x-1}\), we require \(x\ge1\). The graph begins exactly at \((1,0)\), making the domain restriction visible.

7. Why composite functions matter for calculus

Nested functions lead directly to the chain rule.
