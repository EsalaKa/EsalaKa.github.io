Exponential Functions

An exponential function changes by a constant factor over equal changes in the input.

The main idea

\[f(x)=Ab^x,\qquad A\neq0,\quad b>0,\quad b\neq1.\]

The variable appears in the exponent.

1. Constant factor

For \(f(x)=2^x\), the outputs multiply by \(2\) whenever \(x\) increases by one.

2. Exponential growth

If \(b>1\), then \(b^x\) grows as \(x\) increases.

The ODE \(dP/dt=kP\) has solution \(P(t)=P_0e^{kt}\).
