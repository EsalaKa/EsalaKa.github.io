FUNCTIONS 01

What Is a Function?

A function describes how an input determines an output.

The main idea

A function takes an allowed input and assigns it exactly one output.

\[ \text{input} \longrightarrow \text{function} \longrightarrow \text{output} \]

If the input is \(x\), the corresponding output is often written \(f(x)\).

1. A simple example

Suppose the rule is

\[ f(x)=2x+1. \]

If the input is \(3\), then

\[ f(3)=2(3)+1=7. \]

So the function assigns the input \(3\) to the output \(7\).

2. A function is a relationship

The function

\[ f(x)=x^2 \]

describes a relationship between an input \(x\) and an output \(f(x)\).

For example,

\[ f(2)=4, \qquad f(3)=9. \]

Changing the input may therefore change the output.

3. Exactly one output

For a relationship to be a function, each allowed input must have exactly one output.

For example,

\[ f(2)=5 \]

cannot simultaneously mean that the same function gives

\[ f(2)=8. \]

One input cannot be assigned two different outputs by the same function.

4. Different inputs may have the same output

The restriction applies from input to output, not the other way around.

For example, with

\[ f(x)=x^2, \]

we have

\[ f(2)=4 \]

and

\[ f(-2)=4. \]

Two different inputs may therefore produce the same output.

5. Function versus formula

A formula is one way of describing a function, but the function is the underlying input-output relationship.

For example,

\[ f(x)=3x-2 \]

gives a formula for determining the output from the input.

Functions can also be represented by graphs, tables or verbal rules.

6. Functions and graphs

Each point on the graph of a function has the form

\[ (x,f(x)). \]

For

\[ f(x)=x^2, \]

the point corresponding to \(x=2\) is

\[ (2,4). \]

The graph therefore shows many input-output pairs at once.

7. Why functions matter for calculus

Calculus studies how outputs change when inputs change.

We begin with a function

\[ y=f(x), \]

change the input from \(x\) to \(x+\Delta x\), and observe the resulting change in the output.

\[ x \longrightarrow f(x) \longrightarrow \text{change in }x \longrightarrow \text{change in }f(x) \]

This relationship between input change and output change leads directly to the derivative.
