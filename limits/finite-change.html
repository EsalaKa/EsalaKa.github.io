CHANGE AND LIMITS 02

Finite Change

A finite change is the actual difference between two distinct values.

The main idea

Suppose \(x\) begins at \(x_1\) and ends at \(x_2\). The change in \(x\) is

\[ \Delta x=x_2-x_1. \]

The symbol \(\Delta x\) therefore represents a difference between two values.

1. Why it is called finite

A finite change has an actual size.

For example, if

\[ x_1=2, \qquad x_2=2.5, \]

then

\[ \Delta x=2.5-2=0.5. \]

Here \(0.5\) is the finite change in \(x\).

2. Writing the final value using \(\Delta x\)

From

\[ \Delta x=x_2-x_1, \]

we can rearrange to obtain

\[ x_2=x_1+\Delta x. \]

If the initial value is simply called \(x\), the new value can therefore be written as

\[ x+\Delta x. \]

This notation will be used repeatedly in calculus.

3. A function also changes

Suppose

\[ y=f(x). \]

Initially, the input is \(x\), so the output is

\[ f(x). \]

After the input changes by \(\Delta x\), the new input is

\[ x+\Delta x, \]

so the new output is

\[ f(x+\Delta x). \]

4. Finding the change in the output

Change always means final value minus initial value.

Therefore,

\[ \Delta y = f(x+\Delta x)-f(x). \]

This formula describes the actual change in the output caused by the finite change \(\Delta x\).

5. Example with \(f(x)=x^2\)

Let

\[ f(x)=x^2. \]

Suppose \(x\) changes from \(2\) to \(2.5\). Then

\[ \Delta x=0.5. \]

The initial output is

\[ f(2)=4, \]

and the final output is

\[ f(2.5)=6.25. \]

Therefore,

\[ \Delta y=6.25-4=2.25. \]

6. The same idea algebraically

For

\[ f(x)=x^2, \]

the new output is

\[ f(x+\Delta x) = (x+\Delta x)^2. \]

Expanding,

\[ f(x+\Delta x) = x^2+2x\Delta x+(\Delta x)^2. \]

Therefore,

\[ \Delta y = f(x+\Delta x)-f(x) \]

gives

\[ \Delta y = 2x\Delta x+(\Delta x)^2. \]

7. The rate over the finite interval

We can now compare the output change with the input change:

\[ \frac{\Delta y}{\Delta x}. \]

For \(f(x)=x^2\),

\[ \frac{\Delta y}{\Delta x} = \frac{2x\Delta x+(\Delta x)^2}{\Delta x}. \]

For \(\Delta x\neq0\),

\[ \frac{\Delta y}{\Delta x} = 2x+\Delta x. \]

This is the average rate of change over the finite interval.

8. The important distinction

A finite change does not mean an infinitely small change.

\[ \Delta x = \text{an actual difference between two values}. \]

It may be large or very small, but while \(\Delta x\neq0\), the two input values remain distinct.

9. Where this leads

For \(f(x)=x^2\), we found

\[ \frac{\Delta y}{\Delta x} = 2x+\Delta x. \]

Now imagine making \(\Delta x\) smaller and smaller:

\[ 0.5,\quad 0.1,\quad 0.01,\quad 0.001,\quad\ldots \]

Then

\[ 2x+\Delta x \]

gets closer and closer to

\[ 2x. \]

This idea of approaching a value is the beginning of the concept of a limit.
