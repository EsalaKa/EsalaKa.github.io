FUNCTIONS 12

Inverse Functions

An inverse function reverses the action of the original function, exchanging inputs and outputs.

The main idea

If a function maps an input \(x\) to an output \(y\), its inverse maps that output back to the original input.

\[ x\xrightarrow{\ f\ }y\xrightarrow{\ f^{-1}\ }x \]

The original function and its inverse therefore describe the same relationship in opposite directions.

1. A simple example

Suppose

\[ f(x)=x+3. \]

The function adds \(3\). To reverse it, subtract \(3\):

\[ f^{-1}(x)=x-3. \]

Hence

\[ f^{-1}(f(x))=x. \]

2. Inverse notation

The notation \(f^{-1}(x)\) means the inverse function of \(f\). It does not mean

\[ \frac{1}{f(x)}. \]

These are different mathematical ideas.

3. Finding an inverse

Consider

\[ f(x)=2x+5. \]

Write \(y=2x+5\), solve for \(x\), then interchange the roles of \(x\) and \(y\):

\[ y-5=2x, \qquad x=\frac{y-5}{2}. \]

Therefore

\[ \boxed{f^{-1}(x)=\frac{x-5}{2}} \]

4. Checking an inverse

A correct inverse must undo the original function:

\[ f^{-1}(f(x)) = \frac{(2x+5)-5}{2} = x. \]

Likewise, \(f(f^{-1}(x))=x\) on the appropriate domain.

5. The graphical meaning

When a function contains the point \((a,b)\), its inverse contains \((b,a)\). Interchanging the coordinates reflects the graph in the line

\[ y=x. \]

The picture shows the key geometric idea:

\[ \boxed{\text{inverse graph}=\text{reflection of the original graph in }y=x} \]

6. Not every function has an inverse

For an inverse function to exist, each output must come from only one input. For example,

\[ f(x)=x^2 \]

gives \(f(2)=4\) and \(f(-2)=4\). Therefore, on all real numbers, \(x^2\) is not one-to-one and has no inverse function.

7. The horizontal line test

A function has an inverse exactly when every horizontal line meets its graph at most once. If a horizontal line meets the graph twice, one output corresponds to two inputs.

8. Restricting the domain

If we restrict

\[ f(x)=x^2 \]

to

\[ x\ge0, \]

then every output comes from only one input. The inverse is

\[ f^{-1}(x)=\sqrt{x}. \]

This graph explains why the domain restriction is necessary: we keep only the one-to-one half of the parabola before reflecting it.

9. Domain and range swap

Because inputs and outputs exchange roles, the domain of a function becomes the range of its inverse, and the range becomes the domain:

\[ \boxed{\operatorname{Dom}(f)=\operatorname{Ran}(f^{-1})} \] \[ \boxed{\operatorname{Ran}(f)=\operatorname{Dom}(f^{-1})} \]

10. Exponential and logarithmic functions

The exponential function

\[ f(x)=e^x \]

has inverse

\[ f^{-1}(x)=\ln x. \]

Therefore

\[ \ln(e^x)=x \]

and, for \(x\gt0\),

\[ e^{\ln x}=x. \]

The exponential graph has range \((0,\infty)\), so the logarithm has domain \((0,\infty)\). The graph makes this domain-range exchange visible.

11. Why inverse functions matter for calculus

Inverse functions allow relationships to be reversed. They are essential for logarithms, inverse trigonometric functions, solving equations and later for differentiating inverse functions.

\[ \boxed{\text{function}\longleftrightarrow\text{inverse function}} \]
