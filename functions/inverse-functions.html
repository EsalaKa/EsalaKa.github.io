FUNCTIONS 12

Inverse Functions

An inverse function reverses the action of the original function.

The main idea

If a function maps an input \(x\) to an output \(y\), its inverse maps that output back to the original input.

\[ x \xrightarrow{\ f\ } y \xrightarrow{\ f^{-1}\ } x \]

1. A simple example

Suppose

\[ f(x)=x+3. \]

The function adds \(3\).

To reverse this, subtract \(3\):

\[ f^{-1}(x)=x-3. \]

So

\[ f^{-1}(f(x))=x. \]

2. Inverse notation

The notation

\[ f^{-1}(x) \]

means the inverse function of \(f\).

It does not mean

\[ \frac{1}{f(x)}. \]

These are completely different expressions.

3. Finding an inverse

Consider

\[ f(x)=2x+5. \]

Write

\[ y=2x+5. \]

Now solve for \(x\):

\[ y-5=2x, \] \[ x=\frac{y-5}{2}. \]

Interchange \(x\) and \(y\):

\[ y=\frac{x-5}{2}. \]

Therefore,

\[ f^{-1}(x)=\frac{x-5}{2}. \]

4. Checking an inverse

A correct inverse should undo the original function.

For

\[ f(x)=2x+5 \]

and

\[ f^{-1}(x)=\frac{x-5}{2}, \]

we have

\[ f^{-1}(f(x)) = \frac{(2x+5)-5}{2} = x. \]

So the inverse works.

5. Not every function has an inverse

For an inverse function to exist, different inputs must not produce the same output.

For example,

\[ f(x)=x^2 \]

gives

\[ f(2)=4 \]

and

\[ f(-2)=4. \]

So on all real numbers, \(f(x)=x^2\) does not have an inverse function.

6. Restricting the domain

If we restrict the domain of

\[ f(x)=x^2 \]

to

\[ x\ge0, \]

then each output corresponds to only one input.

The inverse is then

\[ f^{-1}(x)=\sqrt{x}. \]

7. Graphs of inverse functions

The graphs of a function and its inverse are reflections of each other in the line

\[ y=x. \]

This happens because the coordinates

\[ (x,y) \]

become

\[ (y,x) \]

when input and output are reversed.

8. Exponential and logarithmic functions

The exponential function

\[ f(x)=e^x \]

has inverse

\[ f^{-1}(x)=\ln x. \]

So

\[ \ln(e^x)=x \]

and, for \(x>0\),

\[ e^{\ln x}=x. \]

9. Why inverse functions matter for calculus

Inverse functions allow us to reverse mathematical relationships.

They are especially important for logarithms, inverse trigonometric functions and solving equations.

\[ \text{function} \longleftrightarrow \text{inverse function} \]
