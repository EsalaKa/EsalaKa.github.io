CHANGE AND LIMITS 02

Finite Change

A finite change is the actual difference between two distinct values.

The main idea

If \(x\) begins at \(x_1\) and ends at \(x_2\), then

\[\boxed{\Delta x=x_2-x_1}.\]

The symbol \(\Delta x\) therefore represents an actual difference between two values.

1. Why it is called finite

A finite change has a definite size. If

\[x_1=2,\qquad x_2=2.5,\]

then

\[\Delta x=2.5-2=0.5.\]

The value \(0.5\) is the finite change.

\(2\)
↓ change \(=0.5\)
\(2.5\)

2. Writing the new value

From

\[\Delta x=x_2-x_1\]

we obtain

\[x_2=x_1+\Delta x.\]

If the initial value is called simply \(x\), the new value is

\[\boxed{x+\Delta x}.\]
initial input
\(x\)
↓ add \(\Delta x\)
new input
\(x+\Delta x\)

3. A function also changes

Suppose \(y=f(x)\). At the initial input \(x\), the output is \(f(x)\).

After the input changes by \(\Delta x\), the input becomes \(x+\Delta x\), so the output becomes

\[\boxed{f(x+\Delta x)}.\]
\(x\to f(x)\)

\(x+\Delta x\to f(x+\Delta x)\)

4. Change in the output

Change means final value minus initial value. Therefore

\[\boxed{\Delta y=f(x+\Delta x)-f(x)}.\]

This is the output change caused by the input change \(\Delta x\).

new output
\(f(x+\Delta x)\)
−
old output
\(f(x)\)
↓
\(\Delta y\)

5. Example: \(f(x)=x^2\)

Let \(x\) change from \(2\) to \(2.5\). Then

\[\Delta x=0.5.\]

The outputs are

\[f(2)=4,\qquad f(2.5)=6.25.\]

Hence

\[\boxed{\Delta y=6.25-4=2.25}.\]
\(x: 2\to2.5\)
\(\Delta x=0.5\)

\(y:4\to6.25\)
\(\Delta y=2.25\)

6. The same example algebraically

For \(f(x)=x^2\),

\[f(x+\Delta x)=(x+\Delta x)^2.\]

Therefore

\[\Delta y=(x+\Delta x)^2-x^2\]\[=2x\Delta x+(\Delta x)^2.\]

So

\[\boxed{\Delta y=2x\Delta x+(\Delta x)^2}.\]
\((x+\Delta x)^2-x^2\)
↓ expand
\(x^2+2x\Delta x+(\Delta x)^2-x^2\)
↓
\(2x\Delta x+(\Delta x)^2\)

7. Rate over the finite interval

Compare output change with input change:

\[\frac{\Delta y}{\Delta x}.\]

For \(f(x)=x^2\), when \(\Delta x\ne0\),

\[\frac{\Delta y}{\Delta x}=\frac{2x\Delta x+(\Delta x)^2}{\Delta x}=\boxed{2x+\Delta x}.\]

This is the average rate of change over the finite interval.

\(\Delta y\)
÷
\(\Delta x\)
↓
average rate over the interval

8. Finite does not mean infinitesimal

A finite change may be large or very small, but it remains an actual difference between two distinct values.

\[\boxed{\Delta x\ne0}.\]

For example, \(0.5\), \(0.01\), and \(0.0001\) are all finite changes.

large finite change
\(0.5\)
↓
smaller finite change
\(0.01\)
↓

\(0.0001\)

9. Where this leads

For \(f(x)=x^2\),

\[\frac{\Delta y}{\Delta x}=2x+\Delta x.\]

As \(\Delta x\) becomes smaller and approaches zero, \(2x+\Delta x\) approaches \(2x\).

\[2x+\Delta x\longrightarrow2x.\]

This is the beginning of the idea of a limit.

\(\Delta x=0.5\)
↓
\(0.1\)
↓
\(0.01\)
↓

\(2x+\Delta x\to2x\)
Key takeaways

A finite change \(\Delta x\) is an actual non-zero difference between two input values. For \(y=f(x)\), the corresponding output change is \(\Delta y=f(x+\Delta x)-f(x)\). Their ratio \(\Delta y/\Delta x\) gives the average rate of change over that finite interval and prepares the way for limits.
