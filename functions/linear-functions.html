FUNCTIONS 04

Linear Functions

A linear function changes at a constant rate and has a straight-line graph.

The main idea

A linear function has the form

\[f(x)=mx+c.\]

The constant \(m\) gives the rate of change, and \(c\) gives the output when \(x=0\).

1. The gradient

The number \(m\) is the gradient of the line. It tells us how much the output changes when the input increases by one unit.

\[f(x)=3x+2.\]

The gradient is \(3\), so if \(x\) increases by \(1\), \(f(x)\) increases by \(3\).

2. The intercept

The number \(c\) is the vertical intercept. For \(f(x)=3x+2\),

\[f(0)=2,\]

so the graph crosses the \(y\)-axis at \((0,2)\).

3. Constant rate of change

For any two points \((x_1,y_1)\) and \((x_2,y_2)\),

\[m=\frac{y_2-y_1}{x_2-x_1}.\]

For a linear function this value is constant.

4. Example

For \(f(x)=2x+1\), \(f(1)=3\) and \(f(4)=9\). Hence

\[\Delta x=3,\qquad \Delta y=6,\qquad \frac{\Delta y}{\Delta x}=2.\]

5. Positive and negative gradient

If

\[m\gt0,\]

the function increases. If

\[m\lt0,\]

the function decreases. If \(m=0\), the graph is horizontal.

6. Finding a line from two points

For points \((1,3)\) and \((4,9)\),

\[m=\frac{9-3}{4-1}=2.\]

Using \((1,3)\) in \(f(x)=2x+c\) gives \(c=1\), so \(f(x)=2x+1\).

7. Linear models

Linear functions model constant change. For example, \(C(n)=5n+20\) can represent a fixed charge of \(20\) plus \(5\) per unit.

8. Why linear functions matter for calculus

A straight line has constant slope; a curve usually does not. Calculus measures a curve locally using its tangent slope.

\[\text{straight-line slope}\longrightarrow\text{tangent slope}\longrightarrow\frac{dy}{dx}.\]
