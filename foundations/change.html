FOUNDATIONS 08

Mathematical Change

Change measures the difference between a final value and an initial value.

The main idea

If a quantity changes from an initial value to a final value, its change is

\[ \text{change} = \text{final value} - \text{initial value}. \]

The Greek capital letter \(\Delta\) is commonly used to represent a finite change.

1. Change in \(x\)

If \(x\) changes from \(x_1\) to \(x_2\), then

\[ \Delta x=x_2-x_1. \]

For example, if \(x\) changes from \(3\) to \(8\),

\[ \Delta x=8-3=5. \]

2. Change can be negative

If the final value is smaller than the initial value, the change is negative.

If \(x\) changes from \(8\) to \(3\),

\[ \Delta x=3-8=-5. \]

So the sign of the change tells us the direction of movement.

3. Change in \(y\)

If \(y\) changes from \(y_1\) to \(y_2\), then

\[ \Delta y=y_2-y_1. \]

The same idea applies to any changing quantity.

4. Change in one quantity relative to another

Suppose both \(x\) and \(y\) change.

We can compare their changes using

\[ \frac{\Delta y}{\Delta x}. \]

This tells us how much \(y\) changes for each unit change in \(x\).

5. Average rate of change

For a function \(y=f(x)\), the average rate of change between two points is

\[ \frac{\Delta y}{\Delta x} = \frac{f(x_2)-f(x_1)}{x_2-x_1}. \]

For example, let

\[ f(x)=x^2. \]

Between \(x=1\) and \(x=3\),

\[ \Delta x=3-1=2, \]

and

\[ \Delta y=f(3)-f(1)=9-1=8. \]

Therefore,

\[ \frac{\Delta y}{\Delta x} = \frac82 = 4. \]

6. Finite change

The symbol \(\Delta x\) represents an actual difference between two values. It is a finite quantity.

For example,

\[ \Delta x=0.1 \]

means that \(x\) has changed by \(0.1\).

7. Why this matters for calculus

Ordinary algebra can describe change over a finite interval using

\[ \frac{\Delta y}{\Delta x}. \]

Calculus asks what happens to this rate when the interval becomes arbitrarily small.

\[ \frac{\Delta y}{\Delta x} \quad\longrightarrow\quad \frac{dy}{dx}. \]

This is the central transition from finite change to the derivative.
