FUNCTIONS 05

Quadratic Functions

A quadratic function contains a squared variable and has a curved graph called a parabola.

The main idea

\[f(x)=ax^2+bx+c,\qquad a\neq0.\]

The highest power of \(x\) is \(2\).

1. Shape

If \(a\gt0\), the parabola opens upward. If \(a\lt0\), it opens downward.

2. Example

For \(f(x)=x^2\), values equally far from zero give the same output, so the graph is symmetric about the \(y\)-axis.

3. Roots

Roots satisfy \(f(x)=0\). For

\[x^2-5x+6=(x-2)(x-3),\]

the roots are \(2\) and \(3\).

4. Turning point

A parabola has one turning point: a minimum if it opens upward and a maximum if it opens downward.

5. Completing the square

\[f(x)=a(x-h)^2+k\]

makes the turning point \((h,k)\) visible. For example, \(x^2-4x+7=(x-2)^2+3\), so the turning point is \((2,3)\).

6. Axis of symmetry

For \(a(x-h)^2+k\), the axis is \(x=h\).

7. Quadratic formula

\[x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}.\]

8. Discriminant

If \(b^2-4ac\gt0\), there are two distinct real roots. If it equals zero, there is one repeated real root. If \(b^2-4ac\lt0\), there are no real roots.

9. Why quadratics matter for calculus

A quadratic has changing slope. For example,

\[f(x)=x^2\longrightarrow f'(x)=2x.\]
