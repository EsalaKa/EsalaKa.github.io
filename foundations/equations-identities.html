FOUNDATIONS 03

Equations and Identities

Equations express equality. Identities express equality that holds for every allowed value of the variable.

The main idea

The symbol \(=\) means that the expressions on its two sides have the same value.

\[ \text{left-hand side} = \text{right-hand side} \]

An equation asks when this equality is true. An identity states an equality that is always true for the allowed values.

1. Equality

An equality says that two mathematical expressions represent the same value.

\[ 3+4=7. \]

The equality sign does not mean “the answer comes next”. It means that the two sides have equal value.

Therefore,

\[ 7=3+4 \]

is equally valid.

2. Equations

An equation containing a variable may be true only for particular values of that variable.

For example,

\[ x+3=8 \]

is true when

\[ x=5. \]

The value \(x=5\) is called a solution of the equation.

3. Solving an equation

Solving an equation means finding the value or values that make the equation true.

For example,

\[ 2x+3=11. \]

Subtract \(3\) from both sides:

\[ 2x=8. \]

Divide both sides by \(2\):

\[ x=4. \]

Each step produces an equivalent equation with the same solution.

4. Why we do the same operation to both sides

An equation represents a balance between two equal quantities. If the same quantity is added to both sides, equality is preserved.

\[ a=b \quad\Longrightarrow\quad a+c=b+c. \]

Similarly,

\[ a=b \quad\Longrightarrow\quad a-c=b-c. \]

Multiplying both sides by the same number also preserves equality:

\[ a=b \quad\Longrightarrow\quad ac=bc. \]

Division is valid provided the divisor is not zero:

\[ a=b,\qquad c\neq0 \quad\Longrightarrow\quad \frac{a}{c}=\frac{b}{c}. \]

This is the mathematical reason behind the familiar rule “do the same thing to both sides”.

5. Equivalent equations

Two equations are equivalent when they have the same solutions.

For example,

\[ x+2=6, \] \[ x=4 \]

have the same solution, so they are equivalent equations.

Solving usually consists of replacing an equation by simpler equivalent equations until the variable is isolated.

6. Identities

An identity is an equality that is true for every allowed value of the variable.

For example,

\[ 2(x+3)=2x+6 \]

is true for every real value of \(x\).

An identity is commonly written using

\[ \equiv \]

to emphasise that the equality holds identically:

\[ 2(x+3)\equiv2x+6. \]

7. Equation versus identity

Consider

\[ x+2=5. \]

This is true only when \(x=3\), so it is an equation with a particular solution.

In contrast,

\[ (x+1)^2\equiv x^2+2x+1 \]

is true for every real value of \(x\), so it is an identity.
