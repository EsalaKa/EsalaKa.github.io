FUNCTIONS 02

Function Notation

Function notation identifies a function, its input and the corresponding output.

The main idea

If a function is called \(f\) and its input is \(x\), its output is written \(f(x)\), read “f of x”.

1. Defining a function

For \(f(x)=2x+3\), \(f\) is the name, \(x\) is the input and \(2x+3\) determines the output.

2. Evaluating a function

To find \(f(4)\), replace \(x\) by \(4\): \(f(4)=11\).

3. The input can be any allowed expression

If \(f(x)=x^2+1\), then \(f(a)=a^2+1\) and \(f(x+h)=(x+h)^2+1\).

4. Function names

The letter \(f\) is only a name. We may also use \(g(x)\), \(h(x)\), and others.

5. \(y\) and \(f(x)\)

\(y=2x+1\) and \(f(x)=2x+1\) can describe the same relationship.

6. Function notation does not mean multiplication

\(f(x)\) denotes the value of function \(f\) at input \(x\); the brackets specify the input.

7. Comparing two function values

For \(f(x)=x^2\), \(f(2)=4\) and \(f(5)=25\). The graph shows both values and the change between them.

8. A notation that leads to calculus

If the input changes from \(x\) to \(x+\Delta x\),

\[\Delta y=f(x+\Delta x)-f(x),\qquad \frac{\Delta y}{\Delta x}=\frac{f(x+\Delta x)-f(x)}{\Delta x}.\]
