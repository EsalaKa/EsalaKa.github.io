FOUNDATIONS 01

Number Systems

Different number systems arise because different mathematical problems require different kinds of numbers.

The main idea

We do not have several unrelated kinds of numbers. Instead, the main number systems fit inside one another:

\[ \mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}. \]

The symbol \(\subset\) means is contained in.

So every natural number is an integer, every integer is rational, and every rational number is real.

01

Natural numbers

Natural numbers are the numbers used for counting:

\[ 1,\;2,\;3,\;4,\ldots \]

We write

\[ \mathbb{N}=\{1,2,3,\ldots\}. \]

Some conventions also include \(0\) in \(\mathbb N\), so it is useful to state which convention is being used.

02

Integers

Counting numbers are not enough when negative values are needed. Adding zero and the negative whole numbers gives the integers:

\[ \mathbb{Z} = \{\ldots,-3,-2,-1,0,1,2,3,\ldots\}. \]

Therefore,

\[ \mathbb{N}\subset\mathbb{Z}. \]
03

Rational numbers

Integers are not enough when division produces parts of a whole. A rational number is any number that can be written as

\[ \frac{p}{q}, \qquad p,q\in\mathbb{Z}, \qquad q\neq0. \]

For example,

\[ \frac12,\qquad -\frac34,\qquad 5=\frac51. \]

A number does not have to look like a fraction to be rational. It only needs to be possible to write it as one.

04

Decimals can also be rational

For example,

\[ 0.5=\frac12 \]

and

\[ 0.333\ldots=\frac13. \]

Terminating decimals and repeating decimals are rational numbers.

05

Irrational numbers

Not every number can be written as a fraction of two integers. Such numbers are called irrational.

Examples include

\[ \sqrt{2},\qquad \pi,\qquad e. \]

Their decimal expansions continue indefinitely without eventually repeating a fixed pattern.

06

Real numbers

The real numbers contain both rational and irrational numbers.

\[ \mathbb{R} = \{\text{all rational and irrational numbers}\}. \]

Every point on the ordinary number line represents a real number.

One number can belong to several sets

Consider the number \(3\).

It is a natural number:

\[ 3\in\mathbb{N}. \]

It is also an integer:

\[ 3\in\mathbb{Z}. \]

And because

\[ 3=\frac31, \]

it is rational and therefore real.

\[ 3\in \mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}. \]

The symbol \(\in\) means is an element of.

Why this matters for calculus

Calculus studies quantities that can change continuously. For example, between \(1\) and \(2\) there are infinitely many real numbers.

\[ 1 < 1.1 < 1.01\text{?} \]

But numerical order must be read carefully. For example,

\[ 1<1.01<1.1<2. \]

And no matter how close two different real numbers are, another real number can be found between them.

This continuous number line provides the setting in which we later study limits, derivatives and integrals.

\[ \mathbb{R} \longrightarrow x \longrightarrow f(x) \longrightarrow \lim \longrightarrow \frac{dy}{dx}. \]

Remember the structure

\[ \boxed{\mathbb N} \subset \boxed{\mathbb Z} \subset \boxed{\mathbb Q} \subset \boxed{\mathbb R} \]

Each step enlarges the collection of numbers available to us.
