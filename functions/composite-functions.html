FUNCTIONS 11

Composite Functions

A composite function uses the output of one function as the input of another.

The main idea

If \(g\) acts first and \(f\) acts next, the composite function is written

\[ (f\circ g)(x)=f(g(x)). \]

The expression \(g(x)\) is found first, then its result is used as the input of \(f\).

1. A simple example

Suppose

\[ g(x)=x+2 \]

and

\[ f(x)=x^2. \]

Then

\[ f(g(x)) = f(x+2) = (x+2)^2. \]

So

\[ (f\circ g)(x)=(x+2)^2. \]

2. The order matters

In general,

\[ f(g(x)) \]

is not the same as

\[ g(f(x)). \]

Using the same functions,

\[ f(g(x))=(x+2)^2, \]

while

\[ g(f(x))=x^2+2. \]

These are different functions.

3. Think of functions as stages

A composite function can be viewed as a sequence of operations.

\[ x \longrightarrow g(x) \longrightarrow f(g(x)). \]

The output from the first stage becomes the input to the second.

4. Evaluating a composite function

Let

\[ g(x)=2x+1 \]

and

\[ f(x)=x^2. \]

To find

\[ (f\circ g)(3), \]

first calculate

\[ g(3)=2(3)+1=7. \]

Then

\[ f(7)=49. \]

Therefore,

\[ (f\circ g)(3)=49. \]

5. Reading nested functions

Consider

\[ f(g(x)). \]

Read the expression from the inside outward.

First evaluate

\[ g(x), \]

then apply \(f\) to that result.

This inside-out structure becomes very important in calculus.

6. Domain of a composite function

For

\[ f(g(x)) \]

to be defined, two things must be true: the input \(x\) must be allowed by \(g\), and the output \(g(x)\) must be an allowed input for \(f\).

For example, let

\[ g(x)=x-1 \]

and

\[ f(x)=\sqrt{x}. \]

Then

\[ f(g(x)) = \sqrt{x-1}. \]

For real values,

\[ x-1\ge0, \]

so

\[ x\ge1. \]

7. Why composite functions matter for calculus

Many functions are built from functions inside other functions.

For example,

\[ y=(3x+1)^5 \]

can be viewed as

\[ g(x)=3x+1 \]

followed by

\[ f(u)=u^5. \]

So

\[ y=f(g(x)). \]

Differentiating this kind of structure leads to the chain rule.

\[ f(g(x)) \quad\longrightarrow\quad \text{chain rule}. \]
