FUNCTIONS 13

Transformations of Functions

A transformation changes the position or shape of a graph in a predictable way.

The main idea

Start with a function

\[ y=f(x). \]

Changing the expression inside or outside \(f\) produces a related graph.

1. Vertical translation

Adding a constant outside the function shifts the graph vertically.

\[ y=f(x)+a. \]

If \(a>0\), the graph moves upward by \(a\) units. If \(a<0\), it moves downward.

For example,

\[ y=x^2 \]

becomes

\[ y=x^2+3, \]

which is the same parabola shifted upward by \(3\).

2. Horizontal translation

Changing the input shifts the graph horizontally.

\[ y=f(x-a). \]

If \(a>0\), the graph moves to the right by \(a\) units.

For example,

\[ y=(x-2)^2 \]

is the graph of \(y=x^2\) shifted \(2\) units to the right.

Notice that the horizontal shift appears with the opposite sign inside the function.

3. Vertical stretching

Multiplying the output by a constant changes all vertical distances from the \(x\)-axis.

\[ y=af(x). \]

For example,

\[ y=2x^2 \]

has outputs twice as large as those of

\[ y=x^2. \]

This produces a vertical stretch by factor \(2\).

4. Vertical reflection

Multiplying the function by \(-1\) changes every output \(y\) to \(-y\).

\[ y=-f(x). \]

The graph is therefore reflected in the \(x\)-axis.

For example,

\[ y=-x^2 \]

is the reflection of \(y=x^2\) in the \(x\)-axis.

5. Horizontal reflection

Replacing \(x\) by \(-x\) gives

\[ y=f(-x). \]

This reflects the graph in the \(y\)-axis.

For example, if

\[ f(x)=e^x, \]

then

\[ f(-x)=e^{-x}. \]

The graph of \(e^{-x}\) is the reflection of the graph of \(e^x\) in the \(y\)-axis.

6. Horizontal scaling

Replacing \(x\) by \(bx\) changes horizontal distances.

\[ y=f(bx). \]

If \(b>1\), the graph is compressed horizontally.

For example,

\[ y=\sin(2x) \]

completes its cycle twice as quickly as

\[ y=\sin x. \]

So its horizontal scale is reduced by a factor of \(2\).

7. Several transformations together

Consider

\[ y=2(x-3)^2+1. \]

Starting from

\[ y=x^2, \]

the graph is shifted \(3\) units to the right, stretched vertically by factor \(2\), and shifted \(1\) unit upward.

Its turning point is therefore

\[ (3,1). \]

8. Inside and outside changes

A useful distinction is:

\[ f(x)+a \]

changes the output, so the effect is vertical.

But

\[ f(x-a) \]

changes the input, so the effect is horizontal.

Thinking in terms of input and output makes transformation rules easier to understand rather than memorise.

9. Why transformations matter

Many apparently different functions are transformed versions of a small number of basic functions.

\[ f(x) \quad\longrightarrow\quad A f\!\left(B(x-C)\right)+D. \]

Understanding this structure makes graphs easier to interpret and prepares us for studying how transformations affect derivatives.
