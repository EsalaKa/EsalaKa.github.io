DIFFERENTIATION 14

Optimisation

Optimisation uses derivatives to find the largest or smallest possible value of a quantity.

The main idea

Many mathematical problems ask us to maximise or minimise something.

Examples include maximising area, minimising cost, maximising profit or finding the smallest distance.

If the quantity is represented by a differentiable function \(f(x)\), an interior optimum often occurs where

\[ \boxed{ f'(x)=0 } \]

1. Why derivatives help

Suppose a function increases and then decreases.

At the point where it changes direction, its tangent is typically horizontal.

Therefore,

\[ f'(x)=0. \]

This gives a candidate for a maximum.

Similarly, a function that decreases and then increases has a candidate minimum where its derivative is zero.

2. The optimisation process

A typical optimisation problem follows this structure:

\[ \boxed{ \text{define variables} \rightarrow \text{form a function} \rightarrow \text{differentiate} \rightarrow \text{find candidates} \rightarrow \text{identify the optimum} } \]

The most important step is often not the differentiation itself, but constructing the correct function.

3. Example: maximum area

Suppose a rectangle has perimeter \(20\).

Let its length be \(x\) and its width be \(y\).

Then

\[ 2x+2y=20. \]

Divide by \(2\):

\[ x+y=10. \]

Therefore,

\[ y=10-x. \]

4. Construct the quantity to optimise

The area of the rectangle is

\[ A=xy. \]

Substitute

\[ y=10-x. \]

Then

\[ A(x)=x(10-x). \]

So

\[ A(x)=10x-x^2. \]

We have now expressed the area using one variable.

5. Differentiate

Differentiate the area:

\[ A'(x)=10-2x. \]

At an interior stationary point,

\[ A'(x)=0. \]

Therefore,

\[ 10-2x=0. \]

So

\[ x=5. \]

6. Find the other dimension

Since

\[ y=10-x, \]

we obtain

\[ y=5. \]

Therefore the rectangle with maximum area is a square:

\[ \boxed{ x=5,\qquad y=5 } \]

and its area is

\[ \boxed{ A=25 } \]

7. Confirm that it is a maximum

We have

\[ A'(x)=10-2x. \]

Differentiate again:

\[ A''(x)=-2. \]

Since

\[ A''(5)<0, \]

the graph is concave downward there.

Therefore the stationary point is a maximum.

8. Visual interpretation

The maximum occurs where the graph changes from increasing to decreasing.

9. Example: minimum value

Consider

\[ f(x)=x^2-6x+13. \]

Differentiate:

\[ f'(x)=2x-6. \]

Set the derivative equal to zero:

\[ 2x-6=0. \]

Therefore,

\[ x=3. \]

The function value is

\[ f(3)=9-18+13=4. \]

So the candidate optimum is

\[ (3,4). \]

10. Classify the point

The second derivative is

\[ f''(x)=2. \]

Since

\[ f''(3)>0, \]

the point is a minimum.

\[ \boxed{ \text{minimum value}=4 } \]

11. Local and global optima

A local maximum is larger than nearby values.

A local minimum is smaller than nearby values.

A global maximum is the largest value over the entire domain being considered.

A global minimum is the smallest value over that domain.

A stationary point may be locally optimal without being globally optimal.

12. Endpoints matter

If the allowed domain is a closed interval,

\[ a\le x\le b, \]

a global maximum or minimum may occur at an endpoint rather than at a stationary point.

Therefore, for optimisation on a closed interval, compare the values at

\[ x=a, \qquad x=b, \]

and at all relevant interior critical points.

13. Critical points

A possible optimum can occur where

\[ f'(x)=0, \]

but it may also occur where the derivative does not exist while the function itself is defined.

Such locations, together with stationary points, are called critical points.

So solving \(f'(x)=0\) is important, but it is not the complete optimisation argument in every problem.

14. Constraints

Many optimisation problems contain a constraint.

In the rectangle example,

\[ 2x+2y=20 \]

was the constraint.

We used it to eliminate one variable:

\[ y=10-x. \]

This allowed the quantity being optimised to be written as a function of one variable:

\[ A(x)=x(10-x). \]
\[ \boxed{ \text{constraint} \rightarrow \text{one-variable function} \rightarrow \text{differentiate} } \]

15. Interpretation is essential

A mathematical solution must make sense in the original problem.

For a length, for example,

\[ x>0. \]

A negative stationary value may be mathematically possible for an algebraic function but physically impossible in the application.

Always return to the meaning of the variables before stating the final answer.

16. The practical method

\[ \boxed{ 1.\; \text{Define the variables} } \] \[ \boxed{ 2.\; \text{Identify the quantity to maximise or minimise} } \] \[ \boxed{ 3.\; \text{Use the constraint to obtain a one-variable function} } \] \[ \boxed{ 4.\; \text{Differentiate} } \] \[ \boxed{ 5.\; \text{Find relevant critical points} } \] \[ \boxed{ 6.\; \text{Check endpoints when required} } \] \[ \boxed{ 7.\; \text{Classify and interpret the result} } \]

Optimisation shows how differentiation can turn information about rates of change into practical decisions about maximum and minimum values.
