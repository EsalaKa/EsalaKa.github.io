CHANGE AND LIMITS 06

The Idea of a Limit

A limit describes the value a function approaches when its input approaches a particular value.

The main idea

Suppose that as \(x\) gets closer and closer to \(a\), the value \(f(x)\) gets closer and closer to \(L\).

We write

\[ \boxed{ \lim_{x\to a}f(x)=L } \]

This is read as:

“The limit of \(f(x)\) as \(x\) approaches \(a\) is \(L\).”

1. Reading the notation

Each part has a specific meaning.

\[ \lim \]

means that we are asking about a limiting value.

\[ x\to a \]

means that \(x\) approaches \(a\).

\[ f(x) \]

is the quantity whose behaviour we are observing.

And

\[ L \]

is the value that \(f(x)\) approaches.

2. A simple example

Consider

\[ f(x)=x^2. \]

As \(x\) approaches \(2\),

\[ x^2 \]

approaches \(4\).

Therefore,

\[ \boxed{ \lim_{x\to2}x^2=4 } \]

3. Seeing the approach numerically

Values of \(x\) close to \(2\) produce values of \(x^2\) close to \(4\).

\[ \begin{array}{c|c} x & x^2\\ \hline 1.9 & 3.61\\ 1.99 & 3.9601\\ 1.999 & 3.996001\\ 2.001 & 4.004001\\ 2.01 & 4.0401\\ 2.1 & 4.41 \end{array} \]

From both sides,

\[ x\to2 \]

causes

\[ x^2\to4. \]

4. A limit is about nearby values

A limit describes what happens near a point.

It does not begin by asking what happens exactly at the point.

\[ \boxed{ \text{limit} = \text{behaviour as we approach} } \]

This distinction is one of the most important ideas in calculus.

5. The function value and the limit

There are two different questions:

\[ f(a)=? \]

asks for the value of the function exactly at \(x=a\).

But

\[ \lim_{x\to a}f(x)=? \]

asks what the function approaches as \(x\) gets close to \(a\).

These values are often equal, but they do not have to be.

6. A function can have a limit even when it is undefined at the point

Consider

\[ f(x)=\frac{x^2-1}{x-1}. \]

At \(x=1\), this gives

\[ \frac{0}{0}, \]

so the function is undefined there.

But factorising gives

\[ x^2-1=(x-1)(x+1). \]

Therefore, for \(x\neq1\),

\[ f(x) = \frac{(x-1)(x+1)}{x-1} = x+1. \]

As \(x\) approaches \(1\),

\[ x+1\to2. \]

Therefore,

\[ \boxed{ \lim_{x\to1} \frac{x^2-1}{x-1} = 2 } \]

even though the original function is undefined at \(x=1\).

7. What the graph looks like

The graph behaves like the straight line

\[ y=x+1 \]

except that the point \((1,2)\) is missing.

The open circle means that the point itself is not included.

Nevertheless, the graph approaches height \(2\) from both sides.

That is why the limit is \(2\).

8. Left-hand limit

We can approach \(a\) using values smaller than \(a\).

This is written

\[ \lim_{x\to a^-}f(x). \]

It is called the left-hand limit.

9. Right-hand limit

We can also approach \(a\) using values greater than \(a\).

This is written

\[ \lim_{x\to a^+}f(x). \]

It is called the right-hand limit.

10. When does the two-sided limit exist?

For

\[ \lim_{x\to a}f(x) \]

to exist, the function must approach the same value from both sides.

\[ \boxed{ \lim_{x\to a^-}f(x) = \lim_{x\to a^+}f(x) = L } \]

Then

\[ \lim_{x\to a}f(x)=L. \]

11. When a limit does not exist

Suppose the function approaches \(2\) from the left but \(5\) from the right.

\[ \lim_{x\to a^-}f(x)=2, \] \[ \lim_{x\to a^+}f(x)=5. \]

Since the two sides approach different values,

\[ \boxed{ \lim_{x\to a}f(x) \text{ does not exist.} } \]

12. Why limits solve the secant-line problem

Earlier we found the average rate of change

\[ \frac{f(x+\Delta x)-f(x)} {\Delta x}. \]

We cannot substitute \(\Delta x=0\), because this would involve division by zero.

Instead, we ask what this expression approaches as

\[ \Delta x\to0. \]

That gives

\[ \boxed{ \lim_{\Delta x\to0} \frac{f(x+\Delta x)-f(x)} {\Delta x} } \]

This limit will become the definition of the derivative.

13. The essential distinction

\[ x=a \qquad\text{means}\qquad x\text{ equals }a, \] \[ x\to a \qquad\text{means}\qquad x\text{ approaches }a. \]

A limit is built on the second idea.
