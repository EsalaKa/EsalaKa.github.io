STOCHASTIC CALCULUS 04

The Itô Integral

The Itô integral defines integration with respect to Brownian motion and gives rigorous meaning to the stochastic term in an SDE.

The main idea

In an ordinary integral,

\[ \int_0^T f(t)\,dt, \]

we accumulate contributions over small time intervals.

In stochastic calculus, we also need integrals of the form

\[ \boxed{ \int_0^T H_t\,dW_t } \]

where \(W_t\) is Brownian motion.

This is called an Itô integral.

1. Why ordinary integration is not enough

If \(W_t\) were differentiable, we might try to write

\[ dW_t = \frac{dW_t}{dt}\,dt. \]

But Brownian motion is nowhere differentiable with probability one.

So

\[ \frac{dW_t}{dt} \]

does not exist as an ordinary derivative.

Therefore

\[ \int H_t\,dW_t \]

cannot be defined by ordinary calculus in the usual way.

2. Recall how an ordinary integral is built

Divide

\[ [0,T] \]

into small intervals:

\[ 0=t_0 For an ordinary integral, we form sums such as

\[ \sum_{i=0}^{n-1} f(t_i)\Delta t_i, \]

where

\[ \Delta t_i=t_{i+1}-t_i. \]

As the largest interval becomes smaller, these sums approach

\[ \int_0^T f(t)\,dt. \]

3. Replace time increments by Brownian increments

For the stochastic integral, the corresponding random increment is

\[ \Delta W_i = W(t_{i+1})-W(t_i). \]

So we consider sums of the form

\[ \boxed{ \sum_{i=0}^{n-1} H_{t_i}\Delta W_i } \]

instead of

\[ \sum_{i=0}^{n-1} H_{t_i}\Delta t_i. \]

4. The left endpoint matters

In the Itô definition, the value

\[ H_{t_i} \]

is taken at the beginning of each time interval.

\[ \boxed{ H_{t_i} \left[ W(t_{i+1})-W(t_i) \right] } \]

This means the coefficient multiplying the next Brownian increment depends only on information available up to time \(t_i\).

5. Why future information cannot be used

At time \(t_i\), the future increment

\[ \Delta W_i \]

has not yet occurred.

The process \(H_{t_i}\) must therefore not depend on that future random increment.

This is the basic meaning of saying that the integrand is adapted.

\[ \boxed{ \text{current coefficient} \text{ may depend on the past and present, but not the future} } \]

6. Definition idea

The Itô integral is obtained as the limit of the stochastic sums

\[ \sum_{i=0}^{n-1} H_{t_i} \left[ W(t_{i+1})-W(t_i) \right]. \]

Symbolically,

\[ \boxed{ \int_0^T H_t\,dW_t = \lim \sum_{i=0}^{n-1} H_{t_i}\Delta W_i } \]

where the limit is understood in a stochastic sense rather than as an ordinary pointwise Riemann limit.

7. The simplest example

Take

\[ H_t=1. \]

Then

\[ \int_0^T 1\,dW_t \]

is built from

\[ \sum_{i=0}^{n-1} \Delta W_i. \]

The increments telescope:

\[ \sum_{i=0}^{n-1} \left[ W(t_{i+1})-W(t_i) \right] = W(T)-W(0). \]

Since

\[ W(0)=0, \]

we obtain

\[ \boxed{ \int_0^T dW_t = W_T } \]

8. Constant integrand

If

\[ H_t=c, \]

where \(c\) is constant, then

\[ \int_0^T c\,dW_t = cW_T. \]

Therefore,

\[ \boxed{ \int_0^T c\,dW_t \sim N(0,c^2T) } \]

9. Mean of an Itô integral

Under standard integrability conditions,

\[ \boxed{ E\left[ \int_0^T H_t\,dW_t \right] = 0 } \]

The stochastic integral has mean zero.

This reflects the fact that Brownian increments have mean zero.

10. Why the mean is zero

Consider the approximation

\[ \sum_i H_{t_i}\Delta W_i. \]

Because \(H_{t_i}\) is determined using information available before the next increment,

\[ E[\Delta W_i\mid\text{past}]=0. \]

So each stochastic contribution has conditional mean zero.

This leads to the mean-zero property of the Itô integral.

11. Variance of an Itô integral

The size of the stochastic integral is described by the Itô isometry:

\[ \boxed{ E\left[ \left( \int_0^T H_t\,dW_t \right)^2 \right] = E\left[ \int_0^T H_t^2\,dt \right] } \]

This is one of the central identities in stochastic calculus.

12. Why the square appears

Recall the stochastic rule

\[ (dW_t)^2=dt. \]

Informally,

\[ (H_t\,dW_t)^2 = H_t^2(dW_t)^2 = H_t^2dt. \]

The Itô isometry is the rigorous version of this scaling behaviour.

13. Example with a deterministic integrand

Consider

\[ X = \int_0^T t\,dW_t. \]

Its mean is

\[ E[X]=0. \]

Its variance is

\[ E[X^2] = \int_0^T t^2\,dt. \]

Therefore,

\[ E[X^2] = \frac{T^3}{3}. \]

So

\[ \boxed{ \operatorname{Var}(X) = \frac{T^3}{3} } \]

14. The integral is itself random

An ordinary integral such as

\[ \int_0^T t\,dt \]

is a fixed number.

But

\[ \int_0^T t\,dW_t \]

is a random variable.

\[ \boxed{ \text{integrating with respect to Brownian motion produces randomness} } \]

15. Integral form of an SDE

Consider

\[ dX_t = a(X_t,t)\,dt + b(X_t,t)\,dW_t. \]

Its integral form is

\[ \boxed{ X_t = X_0 + \int_0^t a(X_s,s)\,ds + \int_0^t b(X_s,s)\,dW_s } \]

The first integral describes accumulated drift.

The second describes accumulated stochastic fluctuation.

16. Example with constant coefficients

Consider

\[ dX_t = \mu\,dt + \sigma\,dW_t, \qquad X_0=x_0. \]

Integrating from \(0\) to \(t\),

\[ X_t-X_0 = \int_0^t\mu\,ds + \int_0^t\sigma\,dW_s. \]

Therefore,

\[ X_t = x_0+\mu t+\sigma W_t. \]

Hence,

\[ \boxed{ X_t = x_0+\mu t+\sigma W_t } \]

17. Distribution of this solution

Since

\[ W_t\sim N(0,t), \]

we have

\[ \sigma W_t \sim N(0,\sigma^2t). \]

Therefore,

\[ \boxed{ X_t \sim N( x_0+\mu t,\, \sigma^2t ) } \]

So

\[ E[X_t] = x_0+\mu t \]

and

\[ \operatorname{Var}(X_t) = \sigma^2t. \]

18. The stochastic integral creates the variance

In the previous SDE,

\[ \mu t \]

determines the shift in the mean.

The term

\[ \sigma W_t \]

creates the random spread.

\[ \boxed{ \text{drift} \rightarrow \text{mean movement} } \] \[ \boxed{ \text{Itô integral} \rightarrow \text{random variability} } \]

20. Itô versus ordinary integration

\[ \boxed{ \int f(t)\,dt \quad \text{accumulates against time} } \] \[ \boxed{ \int H_t\,dW_t \quad \text{accumulates against Brownian motion} } \]

The second integral is random and requires stochastic definitions because Brownian motion is irregular.

21. Itô versus Stratonovich

The Itô integral evaluates the integrand using the left endpoint of each interval.

Another stochastic integral, called the Stratonovich integral, uses a different limiting convention.

The two interpretations are related but obey different calculus rules.

This section uses the Itô convention.

22. Why Itô calculus is important

The Itô integral makes SDE notation mathematically meaningful.

It allows us to define random accumulated changes and to derive properties such as means, variances and probability distributions.

23. The structure to remember

\[ \boxed{ \int_0^T H_t\,dW_t } \] \[ \boxed{ \approx \sum_i H_{t_i}\Delta W_i } \] \[ \boxed{ E\left[ \int_0^T H_t\,dW_t \right]=0 } \] \[ \boxed{ E\left[ \left( \int_0^T H_t\,dW_t \right)^2 \right] = E\left[ \int_0^T H_t^2\,dt \right] } \]

24. The central idea

The Itô integral is the stochastic counterpart of ordinary accumulation.

\[ \boxed{ \text{ordinary small contribution} = f(t)\,dt } \] \[ \boxed{ \text{stochastic small contribution} = H_t\,dW_t } \]

Once this integral is defined, stochastic differential equations can be treated as genuine integral equations rather than symbolic expressions.
