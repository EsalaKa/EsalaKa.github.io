FUNCTIONS 12

Inverse Functions

An inverse function reverses the action of the original function, exchanging inputs and outputs.

The main idea

If a function maps an input \(x\) to an output \(y\), its inverse maps that output back to the original input.

\[x\xrightarrow{\ f\ }y\xrightarrow{\ f^{-1}\ }x\]

The original function and its inverse therefore describe the same relationship in opposite directions.

1. A simple example

If \(f(x)=x+3\), then the inverse must subtract \(3\):

\[f^{-1}(x)=x-3.\]

Hence \(f^{-1}(f(x))=x\).

2. Inverse notation

\(f^{-1}(x)\) means the inverse function. It does not mean \(1/f(x)\).

3. Finding an inverse

For \(f(x)=2x+5\), write \(y=2x+5\), solve for \(x\), then swap the variable names:

\[x=\frac{y-5}{2}.\]
\[\boxed{f^{-1}(x)=\frac{x-5}{2}}\]

4. Checking an inverse

\[f^{-1}(f(x))=\frac{(2x+5)-5}{2}=x.\]

A correct inverse undoes the original function.

5. The graphical meaning

If \((a,b)\) lies on \(y=f(x)\), then \((b,a)\) lies on \(y=f^{-1}(x)\). The two graphs are therefore exact reflections in \(y=x\).

For example, the point \((1,3)\) on \(y=2x+1\) corresponds exactly to \((3,1)\) on \(y=(x-1)/2\).

6. Not every function has an inverse

For \(f(x)=x^2\), both \(2\) and \(-2\) produce \(4\). So on all real numbers, \(x^2\) is not one-to-one.

7. The horizontal line test

A function has an inverse exactly when every horizontal line meets its graph at most once.

The horizontal line \(y=4\) meets \(y=x^2\) at the exact points \((-2,4)\) and \((2,4)\).

8. Restricting the domain

If we restrict \(f(x)=x^2\) to \(x\ge0\), every output has one input and

\[f^{-1}(x)=\sqrt{x}.\]

Because both axes use the same scale, the reflection across \(y=x\) is geometrically exact.

9. Domain and range swap

\[\boxed{\operatorname{Dom}(f)=\operatorname{Ran}(f^{-1})}\]\[\boxed{\operatorname{Ran}(f)=\operatorname{Dom}(f^{-1})}\]

10. Exponential and logarithmic functions

\(e^x\) and \(\ln x\) are inverse functions:

\[\ln(e^x)=x,\qquad e^{\ln x}=x\quad(x\gt0).\]

Again, corresponding points swap coordinates. For example, \((0,1)\) lies on \(y=e^x\), while \((1,0)\) lies on \(y=\ln x\).

11. Why inverse functions matter for calculus

Inverse functions are essential for logarithms, inverse trigonometric functions, solving equations and differentiating inverse relationships.

\[\boxed{\text{function}\longleftrightarrow\text{inverse function}}\]
