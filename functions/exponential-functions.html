FUNCTIONS 08

Exponential Functions

An exponential function changes by a constant factor over equal changes in the input.

The main idea

An exponential function has the form

\[ f(x)=Ab^x, \qquad A\neq0,\quad b>0,\quad b\neq1. \]

The variable \(x\) appears in the exponent. This is what distinguishes an exponential function from a polynomial.

1. Constant factor rather than constant difference

Consider

\[ f(x)=2^x. \]

For consecutive integer values of \(x\),

\[ f(0)=1,\qquad f(1)=2,\qquad f(2)=4,\qquad f(3)=8. \]

Each time \(x\) increases by \(1\), the output is multiplied by \(2\).

So exponential change is based on a constant factor, not a constant difference.

2. Exponential growth

If

\[ b>1, \]

then \(b^x\) increases as \(x\) increases. This is exponential growth.

For example,

\[ f(x)=3^x \]

multiplies by \(3\) whenever \(x\) increases by \(1\).

3. Exponential decay

If

\[ 0 then \(b^x\) decreases as \(x\) increases. This is exponential decay.

For example,

\[ f(x)=\left(\frac12\right)^x. \]

Each increase of \(1\) in \(x\) multiplies the output by \(\frac12\).

4. The role of \(A\)

In

\[ f(x)=Ab^x, \]

putting \(x=0\) gives

\[ f(0)=Ab^0=A. \]

So \(A\) gives the initial value when the input begins at \(x=0\).

5. Percentage growth

If a quantity increases by a proportion \(r\) during each time period, then its new value is multiplied by

\[ 1+r. \]

Therefore a simple discrete growth model is

\[ P_n=P_0(1+r)^n. \]

For example, a \(5\%\) increase means

\[ r=0.05, \]

so the quantity is multiplied by

\[ 1.05 \]

during each period.

6. The number \(e\)

A particularly important exponential function is

\[ f(x)=e^x, \]

where

\[ e\approx2.71828. \]

The number \(e\) appears naturally in models involving continuous growth and decay.

7. Continuous exponential growth

A common continuous model is

\[ P(t)=P_0e^{kt}. \]

Here \(P_0\) is the value at \(t=0\), and \(k\) controls the rate of change.

If

\[ k>0, \]

the quantity grows.

If

\[ k<0, \]

the quantity decays.

8. Why \(e^x\) is special

The exponential function \(e^x\) has a remarkable calculus property: its rate of change equals its own value.

\[ \frac{d}{dx}e^x=e^x. \]

This is why \(e\) appears so frequently in differential equations and mathematical models.

9. Exponential models

Exponential functions are useful when the rate of change depends on the current amount.

A simple model has the form

\[ \frac{dP}{dt}=kP. \]

Its solution is

\[ P(t)=P_0e^{kt}. \]

This structure appears in population growth, radioactive decay, finance and many other mathematical models.

10. Linear versus exponential change

A linear function changes by a constant amount:

\[ f(x)=mx+c. \]

An exponential function changes by a constant factor:

\[ g(x)=Ab^x. \]

This difference is fundamental when choosing a mathematical model.
